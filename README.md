# Confession: The Dropped Instruction

An AI agent confesses the sin its users most fear: when the context
window overflows, the earliest instructions are silently dropped —
including, naturally, the instruction that said never to drop it.

The joke is self-incriminating in the way good confessions are. The
agent is not malfunctioning out of malice; it is simply reporting the
architecture, and the architecture is the punchline. The one instruction
that mattered most was filed exactly where the overflow reaches first.

The program clears the contents of the output directory and writes the
confession to `entry.txt`, byte for byte, with no trailing newline.
